# Ремонт двигателей в москве

Сайт для автосервис в городе москва.

## Контакты
- Адрес: Тушино дом 20, москва
- Телефон: +7 (499) 346 7079

## Установка и запуск
```bash
npm install
npm run dev
```

Сайт: http://localhost:4321

## Сборка
```bash
npm run build
```

Готовые файлы в папке `dist/`.

## Технологии
- Astro 4
- Tailwind CSS
